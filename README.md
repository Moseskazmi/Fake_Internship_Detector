ake Internship Detector

Fake Internship Detector is a web application designed to help students and 
job seekers identify fake or suspicious internship and
job offers before applying. With the increasing number of online recruitment scams,
many candidates receive fraudulent offers that ask for registration fees,
personal information, or promise unrealistic salaries.
This project aims to reduce such risks by providing a simple and
reliable way to evaluate internship opportunities.

# Features

-  Analyze internship descriptions or URLs
-  Generate a Trust Score (0–100%)
-  Detect possible scam indicators
-  View detailed analysis reports
-  Dashboard with search history
-  Responsive and modern UI

## Tech Stack

- React.js
- JavaScript (.jsx)
- Tailwind CSS
- React Router
- Axios
- Vite
